# E-Mail-Vorlagen für Supabase Auth

Supabase → Authentication → Email Templates. Pro Vorlage **Subject** und **Body (HTML)** einsetzen.

## confirm-signup
Subject: `Bitte bestätige deine E-Mail – FC Beizli Helfereinsatz`
Body: `confirm-signup.html`

## reset-password
Subject: `Neues Passwort – FC Beizli Helfereinsatz`
Body: `reset-password.html`

## magic-link
Subject: `Dein Anmeldelink – FC Beizli Helfereinsatz`
Body: `magic-link.html`

## change-email
Subject: `E-Mail-Änderung bestätigen – FC Beizli`
Body: `change-email.html`
